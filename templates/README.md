# Watermark Templates

Taruh file template watermark dalam format PNG di folder ini.

## Cara Penggunaan

1. Screenshot watermark yang ingin dihapus dari video
2. Crop hanya area watermark saja
3. Simpan sebagai file PNG
4. Rename sesuai config di `src/services/watermarkRemover/config.js`

## Contoh

- `wm1.png` — Template watermark pertama (misal: logo TikTok)
- `wm2.png` — Template watermark kedua (misal: username creator)

## Format

- Format: PNG (RGBA)
- Ukuran: Sesuai ukuran watermark di video
- Background: Transparan atau sesuai warna asli watermark
